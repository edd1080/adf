# Changelog

Todos los cambios relevantes de ADF se documentan aquí.

## 0.1.0 — 2026-08-11

- CLI local con `init`, `doctor`, `status`, `next` y `update`.
- Bootstrap greenfield/brownfield con preview, preservación, merge y rollback.
- Estado externo por sesiones, lifecycle G0–G6 y gates humanos G1–G4.
- Siete skills ADF y ocho skills de Matt Pocock fijadas, atribuidas y verificadas.
- Adaptadores compartidos para Codex y OpenCode.
- Preset, workflow, step y bundle local de Spec Kit; el workflow termina antes de implementar.
- Pruebas clean-room, idempotencia, cross-agent, packaging y Day Zero.
- Guías de inicio, arquitectura, upgrades y troubleshooting.
- Distribución pública preparada como `adf-harness-kit`, con wizard `npx` y alias operativo `adf`.

La publicación npm, tag, release, checksums y política de catálogo se evidencian por separado.
